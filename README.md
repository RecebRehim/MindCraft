# MindCraft Academy

Bilingual (English / Azerbaijani) landing site for an IT academy. Inspired by [Code Academy](https://code.edu.az/).

## Features

- White, clean UI with course catalog
- EN / AZ language switcher (persisted in `localStorage`)
- 8-question career fit quiz → program recommendation
- Course signup form with validation

## Programs

- AI Engineering
- Backend Development
- Frontend Development
- Cybersecurity
- Data Engineering
- QA & Test Engineering
- IT Helpdesk

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
